Start here

The Fed pays banks interest on the {{dfn_reserves}} they keep with it, at the rate called {{dfn_iorb}}, while {{dfn_sofr}} measures what {{dfn_overnight}} borrowing against Treasury securities costs in the {{dfn_repo}} market. The gap between the two, counted in {{dfn_bp}}, is the spread the model repository forecasts. This repository asks two questions that forecast cannot: how much cash banks can deploy before the spread starts to rise (H7m), and what moved it during each episode of pressure (H10). The Fed’s own lender of last resort for this market is {{dfn_srf}}, and one of the findings below asks how often SOFR rose above its rate. Every chart is descriptive development evidence; only days after registration can confirm or refute anything.

How it is built

  • Nothing on the page is typed. Every figure is read from a published record through one reader that refuses a figure no record carries, or computed by a tested function from the parent’s published panel at the pin, after its digest check.
  • Every chart is drawn from a data file written by the same script and embedded in the page. A chart whose data the records cannot yield stops the build; a data file that is not what the inputs build fails the check.
  • A placeholder left unfilled is an error, and so is a number typed into the template.
  • The page is built on main and never committed. A pull request that carries the built file or its data fails.
  • Development evidence is labelled beside each figure. Only prospective confirmation days confirm a claim; H7m’s stage verdict is a development-tier outcome printed from its record.
