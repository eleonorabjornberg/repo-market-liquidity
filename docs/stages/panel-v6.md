# Panel version 6: the Phase 3 panel with the second H10 declaration's inputs

**Development data, not a verdict.** Nothing here is scored. This page records a panel, not a result. It builds the panel that
`docs/decisions/h10-method-2.md` section 1 names ("Panel version 6 (named, not built)"), for directive #209 (H10's second declaration,
step 2). It is beside version 5, never in place of it.

## What it is

Version 6 is version 5's build at the same pin (`2032de4`), with six columns added **after** version 5's. Version 5, its manifest and
the registered H10 method's inputs are not touched: every version 5 cell is unchanged in version 6, and the dates are the same
(`tests/test_panel_v6.py`, `test_every_version_5_cell_is_unchanged_and_no_date_is_added`). The readers' default stays version 5
(`panel.CURRENT_VERSION`, `h10_apply.PANEL_VERSION`); only the second declaration reads version 6. The manifest is
`metadata/phase3_panel_v6_manifest.json`, generated by `scripts/build_panel.py --version 6`, never edited by hand, and names
version 5's digest (`v5_sha256`).

## Guards

- `pd_fails.check_declared_lag`, called by the build, refuses a week that the declaration would let a row read before it is public
  (`LookAheadError`); the mutation is recorded in `tests/test_pd_fails.py` and `tests/test_panel_v6.py`.
- The extract and the snapshot refuse a week published on a day the parent's lockbox holds (`LookAheadError`).
- The build refuses a panel that runs past the last day the repo operation snapshots cover (`StaleReadError`).
- The panel ends at the parent's development end, 2026-09-03.
